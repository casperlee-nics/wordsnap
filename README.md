# 拍照背單字（WordSnap）

Android 背單字 App。Kotlin + Jetpack Compose，單字存在手機裡（Room 資料庫）。

## 目前版本 0.67（暫定名稱：像素單字）

v0.67 的改變：
- 複習改成快速單字卡：卡片出現就念英文、同時顯示中文；下方兩個像素按鈕「不記得」（人物＋問號）、「記得」（人物＋燈泡），按了直接換下一張
- 新遊戲輸入暱稱、選角色時播放有希望感的背景音樂（`hope_bgm.ogg`）
- 單字簿頁面播放清淡優雅的背景音樂（`book_bgm.ogg`），念單字時自動變小聲
- 下方工具列：朗讀、複習、加單字、戰鬥
- 「加單字」可選手動輸入（筆和筆記本）或拍照（相機）；按相機直接打開相機
- 單字簿選單移到右上角

v0.66 的改變：
- 朗讀模式按鈕：上一個是向左三角形、暫停是兩條細長方形、下一個／播放是向右三角形
- 外框改回 v0.6 的靛紫色掌機
- 複習、朗讀時長的單字會自動縮小或換行，不會超出外框
- 單字本下方一排按鈕：朗讀、加單字、戰鬥、拍照；戰鬥解鎖時按鈕自動亮起，不會再蓋住最後一個單字
- 單字簿預設顯示「我的單字簿」，想看全部再自己選「全部」
- 拍照提示改為「拍一張課本或文章的照片，我會幫你找出隱藏的單字怪物。」
- 拍照時略過音標（/.../、[...] 裡的字、含 æ ə ˈ 等符號的字）和沒有母音的字母組合
- 貓咪加上左右各兩根鬍鬚

v0.65 的改變：
- 戰鬥：全部答對才會用必殺技把怪物打飛；沒全對怪物留在原地，一樣拿經驗值
- 戰鬥：答錯會被怪物攻擊，畫面多一條自己的 HP；錯超過一半就被打倒，播放有人拖著棺材走到教堂門口的小動畫
- 戰鬥：同一個字累計答錯兩次，會自動變回「沒記住」，回到複習清單
- 戰鬥：中間輸入的字母放大到跟左右兩邊一樣大
- 朗讀模式：上一個、暫停／繼續、下一個改成像素圖示按鈕
- 複習：全部都記住了也能按「複習」，會把整本隨機練一次；有沒記住的字時只考那些
- 人物能力：多顯示「已記住的單字」數量
- 外框改成米白色的早期黑白掌機造型（v0.66 已改回靛紫色）
- 主畫面：城堡下隨機四個人物在原地跳、搖擺、轉身
- 重畫貓咪頭像


- 戰鬥模式：單字簿記住 20 個字（或整本都記住過）就解鎖。電腦念出英文，畫面給第一個和最後一個字母，填出中間的字母；每題 20 個，優先出沒考過的字。答對怪物扣血，最後用種族招式擊倒怪物（人類揮劍、精靈魔法、哥布林炸彈、矮人巨斧、貓族爪擊、龍族火焰、機械族雷射）。答對七成算通過，單字簿名稱前會加 ★
- 20 種像素怪物，戰鬥時有專屬 BGM，念單字時音樂自動變小聲
- 人物等級：戰鬥得到經驗值（每答對一題 10，通過再加 50），升級提升力量、體力、智慧、運氣，每 10 級換一個種族稱號；點左上角人物可看「人物能力」或「離開遊戲」
- 朗讀模式：自動逐字母拼、念整個單字、再念中文解釋，一個接一個循環
- 複習畫面：單字上方有像素場景，每次進入從沙漠、城鎮、魔王城堡、森林、草原、競技場、墳墓、海灘中隨機一個
- 掌上遊戲機外框：仿早期 GBA 的靛紫色，打字時下方按鍵自動收起
- 主畫面：像素世界背景（城堡、山、雲），選單有「新遊戲」「讀取遊戲」「刪除進度」，並播放 30 秒循環的 8-bit 背景音樂（可關閉）
- 刪除進度：選一個存檔刪除，連同它的單字和單字簿
- 捕捉怪物：按「拍照」會先提示「請將鏡頭對準怪物」；選字畫面改成「要新增的怪物」，外框上方有像素怪物
- 冒險者：第一次開啟輸入暱稱，再從 9 個像素人物中選一個（男子、女子、男精靈、女精靈、哥布林、矮人、貓咪、龍、機器人）；點標題列的人物回到主畫面，每個暱稱有自己的進度
- 單字簿：每個暱稱可以建立多本單字簿，上方選單切換「全部」或某一本；拍照後可選擇存到哪一本
- 單字本：字體加大，▶ 播放發音，垃圾桶刪除，點一下可編輯
- 「拍照」：找出照片裡的英文單字，自動略過 the、and 這類常見字，已收錄的字會標示「已有」
- 自動翻譯：沒填中文意思的單字會自動翻成繁體中文（第一次需連網下載約 30 MB 翻譯檔）
- 「複習」：翻卡複習目前單字簿中到期的字，記得的字隔 1、3、7、14、30 天再出現
- 每日提醒：每天晚上 8 點，有字要複習時會發通知
- 像素風格：仿早期掌機遊戲的配色與切角，字型為俐方體 11 號

## 授權

- 背景音樂 `app/src/main/res/raw/title_bgm.ogg`、`battle_bgm.ogg`、`hope_bgm.ogg`、`book_bgm.ogg`：本專案原創，用程式合成的方波／三角波 chiptune。
- 字型 [俐方體 11 號（Cubic 11）](https://github.com/ACh-K/Cubic-11)：免費授權，可商用與再散布，由多個 woff2 子集合併為 `app/src/main/res/font/cubic_11.ttf`。

## 用 Android Studio 執行

1. 把 zip 解壓縮到一個資料夾，例如 `C:\Projects\WordSnap`。
2. 開啟 Android Studio，選 **Open**，選這個資料夾。
3. 第一次開啟會下載需要的元件（Gradle 同步），等右下角進度跑完，可能要幾分鐘。
   如果跳出「升級 Android Gradle Plugin」的提示，可以先按略過。
4. 手機設定 → 關於手機 → 連按「版本號碼」7 次，開啟開發人員選項；
   再到開發人員選項打開「USB 偵錯」。
5. 用 USB 線接上電腦，手機上按「允許」。
6. Android Studio 上方選到你的手機，按綠色 ▶ 執行。

遇到錯誤時，把 Android Studio 下方 Build 視窗的紅字貼給 Claude。
